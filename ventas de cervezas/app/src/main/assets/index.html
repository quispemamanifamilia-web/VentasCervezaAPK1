Ventas, pagos y devolución de cajas

Nueva venta

Cuando la venta esté completamente pagada y se devuelvan todas las cajas, los datos del cliente serán opcionales. Para deudas serán obligatorios. El precio por caja se conserva para la próxima venta, pero puedes modificarlo cuando cambie. Si el dinero recibido supera el total, se registra el vuelto. Si es menor, se registra el saldo pendiente. Las cajas vacías pendientes se calculan por separado.
